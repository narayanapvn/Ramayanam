# Ramayanam Embedded Audio Android Project

Professional offline Android prototype. Android Text-to-Speech has been removed. Playback uses prerecorded narration files embedded in `res/raw` through Android `MediaPlayer`.

The repository intentionally does not contain fake or unlicensed narration/music. Add only final rights-cleared audio using the naming rules in `AUDIO_PRODUCTION_GUIDE.md`.

## Build
Open in Android Studio with JDK 17 / Android SDK 35, sync Gradle, and build an APK.
